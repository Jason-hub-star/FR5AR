# GOAL-run-history — 일어난 일을 되짚는다

FR5 사다리 4/6. 앞: [GOAL-program-slots.md](GOAL-program-slots.md) · 다음: [GOAL-servo-stream.md](GOAL-servo-stream.md).
계약은 **착수할 때 `API-CONTRACT.md` 에 §실행 기록을 신설한다** (아직 없다 · 하드 룰 1).
재료인 §궤적 녹화는 이미 있다.
**착수 시 확장한다** — 지금은 골 한 줄·경계·멈춤 조건만 확정한다 (문서를 미리 살찌우지 않는다).

**이름이 바뀌었다** (2026-08-05 · D74) — `GOAL-optimize-history` 였다. **후보 비교를 뺐다.**

## 골 한 줄

```
실행된 일을 시간축으로 되짚고, 조건이 같은 궤적만 비교 대상으로 내보낸다
verified by 재생이 실기에 닿지 않음을 증명하는 검증 + 조건 불일치 run 이 제외되는 것
while preserving 사다리 1~3 green 과 "재생은 재실행이 아니다" 원칙.
details in docs/goals/GOAL-run-history.md
```

## 경계 (지금 확정하는 것)

- **재생은 실기 명령을 보내지 않는다.** 시간축 시각화일 뿐이고, 실기 cmd 허용목록
  (`jog`·`moveJ`·`gripper`·`mode`·`stop`)에 재생용 이름을 더하지 않는 것으로 구조가 보증한다
- **비교 화면은 여기 없다.** FR5 는 `run` 을 내보내고 **관제화면이 비교한다** (D74) —
  `GOAL-dash-metrics-compare.md`(L3) · `GOAL-dash-motion-compare.md`(L4)가 그 주인이다.
  같은 비교를 두 곳에 만들면 둘이 어긋나는 날 어느 쪽이 맞는지 아무도 모른다
- **후보 경로를 생성하지 않는다.** 최적해 탐색은 PRD `§범위 밖`이고, 시뮬레이터는 안 들인다
- 기록은 `~/fr5-data/history/` — 배포 트리 밖. 상태 원본은 보존기간·다운샘플 규칙을 둔다
- History 는 **읽기 전용 화면이다.** 여기서 로봇을 움직이는 버튼을 만들지 않는다

## 비교가 정직하려면 — 조건이 같아야 한다 (D74)

`run` 과 궤적은 **잰 조건을 함께 싣는다.** 이게 없으면 "A 가 B 보다 몇 % 빠르다" 가 거짓말이 된다 —
속도 상한 10%로 잰 것과 30%로 잰 것을 나란히 놓게 된다.

| 필드 | 뜻 | 없으면 |
|---|---|---|
| `stamp` | 잰 조건 — `robotId`·`toolId`/`userId`·펌웨어·속도 상한·그리퍼 힘·작업영역 판 | 다른 조건끼리 비교된다 |
| `fps` | 고정 샘플 주기 | 성긴 샘플이 더 빨라 보인다 |
| `startPose` | 출발 자세 | 출발이 달라 생긴 차이를 동작 차이로 읽는다 |
| `endReason` | `done`/`timeout`/`gateRefused`/`estop`/`collision`/`disconnect` | 게이트에 막혀 끊긴 run 이 "빠른 run" 으로 섞인다 |
| `dropped` | 결손 프레임 수 | 빠진 구간만큼 짧아 보인다 |
| `purpose` | `measure`(조건 차단) / `collect`(일부러 랜덤화) | 학습용과 측정용이 한 폴더에 섞여 둘 다 못 쓴다 |

**`measure` 인데 `stamp` 가 다르거나 `dropped > 0` 이거나 `endReason != done` 이면 비교에서
제외하고, 화면이 그 이유를 말한다.** 조용히 빼면 표가 왜 비었는지 아무도 모른다.

## Blocked stop condition

- 기록 용량이 상한을 넘기면 멈춘다 (다운샘플 규칙이 선행 재료)
- 조건 필드가 옛 궤적에 없어 비교 대상이 0개가 되면 멈추고 **재녹화부터** 한다 —
  없는 값을 추정해 채우지 않는다
- 무진전 3패스면 blocked. 보고 형식: 재현됨 / 근사됨 / 막힘 / 불확실

## 모방학습과의 관계

시연 재현(모방학습)은 이 골이 아니라 **사다리 3의 실행 관문을 그대로 쓴다** —
approve 후 run, 매 스텝 안전 게이트. 다만 궤적의 출처가 사람이 아니라 학습된 정책이라
`source`(`demo`/`postproc`/`policy`)를 기록에 남겨 History 에서 구분한다.
선은 D45 가 그었다 — **시연 1건 → 궤적 1건 재생, 일반화 없음.** 기술 지형은 별도 조사가 있다.
