# GOAL-imitation-demo — 보여준 작업을 배워서 한다

FR5 사다리 6/6. 앞: [GOAL-servo-stream.md](GOAL-servo-stream.md).
근거는 `docs/research/vision-imitation.md`, 범위는 D47.
**착수 시 확장한다** — 지금은 골 한 줄·경계·멈춤 조건까지만 (하드웨어·팀 결정 대기).

## 골 한 줄

```
같은 작업을 사람이 여러 번 시연하면, 학습된 정책이 그 작업을 스스로 수행한다
verified by 실기 성공률 실측(예: 5회 중 3회) + 모든 프레임이 게이트를 통과했다는 기록
while preserving stop 최우선·승인 관문·사다리 1~5 green.
details in docs/goals/GOAL-imitation-demo.md
```

## 경계 (지금 확정하는 것)

- **범위는 D47** — 시연 수집 → 학습 → 수행까지. 배운 적 없는 작업을 스스로 계획하는 것은
  범위 밖이다 (PRD)
- **정책이 로봇을 직접 잡지 않는다.** 학습 도구는 브리지에게 요청을 보내고, 모든 프레임이
  서보 스트리밍 게이트를 통과한다. xmlrpc 는 연결이 하나뿐이라 예외를 만들 수 없다
- **학습은 오프라인이다** — 파일을 내보내 GPU 에서 돌린다. 학습 코드가 로봇 옆 브리지에서
  돌지 않는다
- **정책 실행도 승인 관문을 탄다** — 사람이 검토하지 않은 궤적을 자동으로 흘려보내지 않는다
- 시연 데이터는 `~/fr5-data/demos/`. 사람이 찍히므로 열람 범위·보존기간을 촬영 전에 정한다

## 선행 조건 (하나라도 없으면 착수 불가)

| 조건 | 상태 |
|---|---|
| 서보 스트리밍 경로 (사다리 5) | 미구현 |
| 텔레오퍼레이션 입력 (게임패드·3D 마우스) | 미확보 — ±1° 버튼으로 30~50회 시연은 불가능하다 |
| 손목 뎁스카메라 + hand-eye 캘리브레이션 | 미확보 (D405 유력, 데이터시트 재확인 필요) |
| 학습용 GPU | 미확보 |
| 시연 30~50회 (단순 pick-place 기준) | 위가 다 돼야 시작 |

## Blocked stop condition

- 위 선행 조건 중 하나라도 없으면 **착수하지 않는다** — 반쯤 만들어두면 안전 경계만 흐려진다
- 학습이 수렴하지 않으면 데이터를 늘리기 전에 **시연 품질**부터 본다 (조종이 느리면
  정책도 느리게 배운다)
- 정책 출력이 게이트를 상시 발동시키면 멈춘다 — 상한을 푸는 게 아니라 행동 표현을 바꾼다
- 무진전 3패스면 blocked. 보고 형식: 재현됨 / 근사됨 / 막힘 / 불확실
