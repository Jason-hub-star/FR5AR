# GOAL-optimize-history — 후보를 비교하고, 일어난 일을 되짚는다

FR5 사다리 4/6. 앞: [GOAL-program-slots.md](GOAL-program-slots.md) · 다음: [GOAL-servo-stream.md](GOAL-servo-stream.md).
계약은 `docs/ref/API-CONTRACT.md` §프로그램 슬롯·실행 기록.
**착수 시 확장한다** — 지금은 골 한 줄·경계·멈춤 조건만 확정한다 (문서를 미리 살찌우지 않는다).

## 골 한 줄

```
같은 작업의 후보 경로를 나란히 비교해 하나를 승인하고, 실행된 일을 시간축으로 되짚는다
verified by 후보 2개 비교 실렌더 + 재생이 실기에 닿지 않음을 증명하는 검증
while preserving 사다리 1~3 green 과 "재생은 재실행이 아니다" 원칙.
details in docs/goals/GOAL-optimize-history.md
```

## 경계 (지금 확정하는 것)

- **재생은 실기 명령을 보내지 않는다.** 시간축 시각화일 뿐이고, 실기 cmd 허용목록
  (`jog`·`moveJ`·`gripper`·`stop`)에 재생용 이름을 더하지 않는 것으로 구조가 보증한다
- **최적해를 찾지 않는다** (PRD 범위 밖). 사람이 낸 후보 몇 개를 비교할 뿐이다
- **브라우저 안에서 물리연산을 하지 않는다** — 시뮬레이터 선정은 아직 결정하지 않는다 (보류)
- 기록은 `~/fr5-data/history/` — 배포 트리 밖. 상태 원본은 보존기간·다운샘플 규칙을 둔다
- History 는 **읽기 전용 화면**이다. 여기서 로봇을 움직이는 버튼을 만들지 않는다

## Blocked stop condition

- 시뮬레이터 없이 "후보 비교"의 근거를 만들 수 없으면 멈추고 **무엇을 비교할지부터** 정한다 —
  경로 길이·시간 추정은 FK 보간으로 가능하지만 충돌 판정은 아니다
- 기록 용량이 상한을 넘기면 멈춘다 (다운샘플 규칙이 선행 재료)
- 무진전 3패스면 blocked. 보고 형식: 재현됨 / 근사됨 / 막힘 / 불확실

## 모방학습과의 관계

시연 재현(모방학습)은 이 골이 아니라 **사다리 3의 실행 관문을 그대로 쓴다** —
approve 후 run, 매 스텝 안전 게이트. 다만 궤적의 출처가 사람이 아니라 학습된 정책이라
`source` 를 기록에 남겨 History 에서 구분한다. 선은 D45 가 그었다 —
**시연 1건 → 궤적 1건 재생, 일반화 없음.** 기술 지형은 별도 조사가 있다.
