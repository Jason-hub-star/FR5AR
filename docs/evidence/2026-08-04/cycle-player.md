# 화면이 한 사이클을 돌린다 — 시간축 (2026-08-04, 4차)

골사다리 `GOAL-dash-cycle-player` 2/4. 그림: `cycle-t02.png` · `cycle-t13.png` · `cycle-t22.png`

## 컨베이어를 돌리는 코드를 안 짰다

**"롤러를 돌린다" 는 두 번 틀린 답이었다.**

- 버려진다 — F8·F10·V4 어디에도 안 이어진다
- **애초에 안 보인다** — 텍스처 없는 매끈한 원통은 아무리 돌려도 화면이 안 변한다
  (화이트 모형이라 표면에 기준점이 없다)

대신 **시간축 재생기**를 짰다. 같은 코드가 넷을 먹는다 — 지금(목업) · 팀원 sim(L3) ·
**동작 3벌(L4 · 와우모먼트)** · 기록 되감기(V4). 컨베이어는 **작업물이 그 위를 지나가면서**
일한다.

## 팔은 베이스만 돈다 — 지어내지 않았다

`aimDeg` 가 25°→135°→0° 로 바뀌는 것은 **베이스가 목표 쪽을 보는 것**이고, 이건
`atan2` 로 나오는 기하학적 사실이다. **6축 관절 궤적은 안 만들었다** — 그건 시연 녹화가
있어야 하고(`GOAL-imitation-demo.md`), 없는 궤적을 지어내면 **F10 의 비교 자체가 거짓이 된다.**
`path.js` 의 `createPlayer` 가 같은 재생기에 붙을 자리는 비워 뒀다.

## 게이트를 세 번 깨뜨렸다

| 주입 | 잡혔나 |
|---|---|
| `stage` 를 안 적은 사건이 0 으로 되돌린다 | **exit 1** — "탄두 단계가 되돌아갔다 @24 (3 → 0)" |
| 원본 배열을 제자리 정렬한다 | **exit 1** — 입력 배열을 건드렸다 |
| 범위 밖 시각을 안 자른다 | **exit 1** — 음수·끝 넘음 둘 다 |

게이트가 보는 것 — 망가진 입력 8종 × 시각 6개에서 **안 던진다** · 같은 `t` 는 같은 값
(**되감기가 성립하는 조건**) · 진행이 뒤로 안 간다 · **탄두가 되살아나지 않는다** ·
시계·난수를 안 본다 · **관제화면에 로봇 명령 경로 0건**(D36).

## 실렌더가 잡은 것 셋

1. **스크럽을 0 으로 당기면 작업물이 사라졌다.** "시각이 0 인가" 로 재생 여부를 판정해서
   *처음으로 돌린 상태*와 *0초 장면*이 구별되지 않았다 → **`armed`(재생 모드)를 따로 뒀다.**
   덤으로 사각지대 하나가 드러났다 — 막대가 0 에 있을 때 0 자리를 누르면 값이 안 바뀌어
   React 가 `onChange` 를 안 낸다. `pointerdown` 에서 재생 모드로 들어가게 했다
2. **바닥 표식이 작업대 밑에 깔렸다.** 작업물은 900mm 위에 있는데 표식만 바닥이라 상판이
   가렸다 → 작업물과 같은 높이로
3. **안 보이는 표식이 원점에 앉아 방 밖까지 상자를 늘렸다** — `scene-axes.sh` 가
   `방 z 범위 [-4.13, 0.30]` 로 잡았다(상한 0.3). 필요할 때 만들게 고쳤다

## 탄두를 크게 그리지 않았다

12m 방에서 Ø65×220mm 는 몇 px 이라 전경에서 안 보인다. **그래도 안 키웠다** — 치수가
실물(페트병) 기준이고, 키우면 AR 에서 사람이 충돌 여지를 오판한다(D51). 크기 대신
**따라다니는 파란 표식**을 줬다. 색은 `--c-info`(시뮬레이션)다 — 초록(정상)·빨강(경고)과
섞으면 상태색이 장식색이 된다.

증거 그림은 그래서 **셀을 3.5m 거리에서** 찍었다 (배치 전경에서는 판정이 안 선다).

## 확인하지 않은 것

- **손으로 안 눌렀다.** 전부 합성 이벤트다 (GAP OPEN 유지)
- **폰에서 안 봤다** — 재생 막대를 시점 버튼 아래로 내리는 CSS 만 넣었고 실기 미확인
- **긴 재생을 안 돌렸다** — 24초 사이클을 몇 바퀴 돌렸을 때 프레임·메모리가 어떤지 미측정
- **AMR 은 안 움직인다** — series 가 AMR 시간을 선언하지 않는다. 계약을 늘릴지 정해야 한다
- `getSeries` 가 **어느 배치안에나 같은 목업**을 준다 — 실물은 시연 녹화에서 온다
