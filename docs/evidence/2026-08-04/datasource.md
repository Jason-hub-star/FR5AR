# 데이터 경계를 팠다 — 화면이 출처를 모른다 (2026-08-04, 3차)

골사다리 `GOAL-dash-datasource` 1/4. **관제화면을 맵 편집기에서 관제화면으로 옮기는 첫 칸.**

## 무엇이 문제였나

`SHARED-CORE.md` §4 와 `ARCHITECTURE.md` §확장성이 `Shared/data/datasource/` 를
**"데이터가 어디서 오는지 아는 유일한 곳"** 으로 선언했는데 **폴더가 비어 있었다.**
형제 둘은 각자 만들어 쓰는데(`FR5/src/data/datasource/` · `TurtleBot/src/data/datasource/`)
정작 Dashboard 몫만 없었다. 그래서

- 배치안 저장이 경계를 우회해 `localStorage` 에 직접 박혀 있었고
- 지표 화면이 21줄짜리 "미착수" 문구인 채였다 — **받아올 데가 없어서**
- L3 완료판정 AC#4(**목업→실물 교체가 파일 한 개**)를 판정할 대상이 없었다

**선언만 있고 지키는 것이 없으면 다음 화면이 또 `fetch` 를 직접 부른다.**

## 무엇을 했나

| 파일 | 무엇 |
|---|---|
| `Shared/data/datasource/index.js` | **한 줄.** `export { datasource } from './mock.js'` — 교체 지점 |
| `Shared/data/datasource/mock.js` | 계약 5개(`getLayouts`·`getLayout`·`putLayout`·`deleteLayout`·`getMetrics`) + 지표 목업 2건 |
| `Shared/data/layout/scenes.js` | 저장 함수 3개를 뗐다 — **팩토리만 남는다** |
| `LayoutEditor.jsx` | 로더 껍데기 + 본체. 저장은 datasource, `saveStore` 호출 0건 |
| `main.jsx` | `const SOURCE = 'mock'` → `datasource.source` |
| `scripts/check/datasource.sh` | **신설 게이트** |

메서드 이름을 계약의 REST 경로와 1:1 로 뒀다 — `http.js` 를 붙일 때 화면이 안 바뀌게.

**"지금 보던 배치안"은 URL 이 든다** (`?scene=s2`). 저장소가 아니라 *이 탭이 무엇을 보고
있나*라서다. `SHARED-CORE.md` §config 가 이미 URL 파라미터를 그 용도로 쓴다.
덤으로 **배치안 링크가 공유 가능해졌다.**

실렌더도 눈으로 봤다 — 프리셋 `cell` 이 전과 같이 뜨고 팔레트·숫자줄·힌트가 그대로다

**그림은 안 남겼다** — 이 폴더가 상한 14개에 닿아 있고(D37), 이번 변경은 화면이
*안 바뀌는* 것이 판정이라 숫자가 그림보다 정확하다.

## 게이트를 일부러 깨뜨렸다

**게이트는 넣는 순간이 아니라 깨뜨려 본 순간부터 게이트다** (`scene-axes.sh` 가 헛돌던 일).

| 주입 | 결과 |
|---|---|
| 화면이 `fetch("/metrics")` 를 직접 부른다 | exit 1 — 파일·줄까지 찍고 실패 |
| 지표 목업 두 판이 **모두 완전**하다 | exit 1 — "선택 필드가 빠진 목업이 없다 (SR_25)" |

`B` 목업에서 `p50`·`p95`·`amrTravelMm`·`waitSec`·`interferences` 를 **일부러 뺐다.**
팀원이 처리량 하나만 내도 화면이 그날 도는지를 목업이 미리 겪는 것이 그 파일의 절반이다.

**주석은 안 센다** — 규약을 설명하는 줄까지 잡으면 규약을 못 적는다.
**`fr5.hint.*` 는 예외다** — "힌트 다시 안 보기"는 데이터가 아니라 이 브라우저의 UI 기억이다.
키 접두사로 좁혀 둬서 배치안·지표를 저장소에 직접 넣는 순간 다시 잡힌다.

## 이번에 드러난 것

**검증 스크립트의 첫 판이 5건 실패했는데 코드가 아니라 시험이 틀렸다.**
팔레트 첫 칸이 소품이 아니라 **문**이라(분류 순서가 `방 껍데기` 부터) `props` 로 세면
문을 놓고도 "안 늘었다"가 된다. **놓인 것 전체**로 고쳐 17/17.
— 실패를 보자마자 코드를 고쳤으면 멀쩡한 코드를 망가뜨렸을 자리다.

## 확인하지 않은 것

- **손으로 안 눌렀다.** 전부 합성 이벤트다 (이번 세션도 · GAP OPEN 유지)
- **폰에서 안 봤다**
- `?scene=` 이 붙은 URL 을 **다른 사람에게 보냈을 때** — 저장은 여전히 브라우저 한 대라
  받는 쪽엔 그 배치안이 없다. **링크 모양만 준비된 상태**다 (팀 공유는 D46 · 이관 H)
- `getMetrics` 는 아직 **아무 화면도 안 부른다** — 소비자는 사다리 3 이다
