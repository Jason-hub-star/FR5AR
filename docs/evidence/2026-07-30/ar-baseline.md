### 3번이 robot.html 과 다른 이유

`robot.html` 은 **128,584 / 10** 이고 여기는 **129,560 / 11** 이다.
차이 **976 삼각형 · 메시 1개**가 **궤적 튜브**(`TubeGeometry`)다 —
`ar.html` 은 튜브를 `robot` 에 붙인다(`stage` 가 아니라. 점이 로봇 로컬 좌표라서).

→ **두 화면의 기준값이 다른 것이 정상이다.** 같은 숫자를 기대하면 오판한다.

### 7번은 CSS 규칙이 "없어야" 통과다

`#arjs-video` 의 **크기를 CSS 로 건드리지 않는 것**이 D13 의 결론이다.
AR.js 가 영상과 검출 캔버스를 같은 크기로 맞추는데, `width:100vw` + `object-fit:cover` 를
넣으면 그 대응이 깨져 **로봇이 마커에서 밀린다.** 규칙이 생기면 회귀다.

남은 미확인은 **폰의 카메라 하나**다.

