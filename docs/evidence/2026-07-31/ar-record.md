# AR 화면 녹화 — 합성 레이어를 픽셀로 검증했다

2026-07-31. 크롬 · `http://localhost:5199/ar.html` (Vite dev).
대상 `AR/src/features/record/screen-record.js`.

## 무엇을 만들었나

⚙ 조정판에 **[● 녹화]** 를 넣었다. 카메라 영상과 3D 겹침을 **한 장으로 합쳐** mp4 로 떨군다.
폰 내장 화면 녹화와 다른 점은 **버튼바·진단판이 안 찍힌다**는 것 — 합치는 것이
영상과 WebGL 캔버스 둘뿐이라 HTML UI 가 애초에 들어가지 않는다.

## 왜 캔버스만 잡으면 안 되나

AR 화면은 두 장이 겹쳐 있다 — 뒤에 카메라 `<video>`(z-index −2), 앞에 **투명한**
WebGL 캔버스 (D13). `renderer.domElement.captureStream()` 은 앞장만 잡으므로
**로봇만 있고 배경이 빈 영상**이 나온다. 그래서 매 프레임 오프스크린 캔버스에 합친다.

합치는 자리는 **`renderer.render()` 바로 다음**이어야 한다. 렌더러가
`preserveDrawingBuffer: false` 라 애니메이션 루프를 벗어나 캔버스를 읽으면 빈 화면이 된다.
그래서 이 모듈은 스스로 루프를 돌지 않고 `capture()` 를 밖에서 부르게 한다.

## 확인한 것

**합성 레이어 — `composeFrame()` 에 직접 그려 `getImageData` 로 읽었다.**

| 검사 | 기대 | 실측 |
|---|---|---|
| 왼쪽 위 (겹침이 있는 자리) | 초록 | `0,255,0,255` |
| 오른쪽 아래 (겹침이 없는 자리) | 카메라 빨강 | `255,0,0,255` |
| 4:3 카메라를 16:9 로 채웠을 때 위쪽 | 노란 띠가 **잘려** 빨강 | `255,0,0,255` |
| 카메라가 아직 없을 때 배경 | **투명**(검게 칠하지 않음) | `0,0,0,0` |

**녹화 왕복 — 실제 버튼을 눌렀다.**

| 검사 | 결과 |
|---|---|
| `supported` · 고른 코덱 | `true` · `video/mp4` (크롬 데스크톱) |
| [● 녹화] 클릭 | 버튼 `■ 정지` · `recording() === true` |

| [■ 정지] 클릭 | 버튼 `● 녹화` 복귀 · `recording() === false` |
| 만들어진 파일 | `video/mp4` · 7,394 byte (프레임 3장) |
| 파일 이름 | `fr5-ar-20260731-185225.mp4` |
| 콘솔 에러 | 0건 |

## 실렌더가 잡은 것

**작은 파일이 `0.0MB` 로 떴다.** 2초짜리 판이 21KB 인데 MB 로만 적으니
**저장에 실패한 것처럼 읽혔다.** 1MB 미만은 KB 로 적게 고쳤다 → `21KB`.

## 확인하지 않은 범위

- **실제 카메라 영상과의 합성은 못 봤다.** 자동화 탭에 웹캠이 안 붙는다.
  위 표의 빨강은 **가짜 카메라 캔버스**다 — 레이어 순서와 cover 잘림은 이걸로 증명되지만,
  진짜 `<video>` 가 같은 자리에 그려지는지는 **폰에서 봐야 한다**
- **녹화 중 fps 비용을 못 쟀다.** 합성이 매 프레임 한 장 더 그린다.
  지금도 고해상도에서 13~14fps 라 **더 떨어질 수 있다** — 폰에서 `[측정 30초]` 로 전후를 잰다
- **iOS 사파리 미확인.** 코덱 후보에 mp4 를 먼저 둔 것은 사파리를 노린 것이지만 확인 전이다
- 공유 시트(`navigator.share`) 경로 미확인 — 데스크톱 크롬은 내려받기로 갔다

## 자동화의 벽 (다음 사람에게)

**백그라운드 탭에서는 `requestAnimationFrame` 이 아예 안 돈다** — `renderer.info.render.frame`
이 0 이었고, 그래서 첫 판이 빈 파일로 나왔다. **제품 결함이 아니다.**
`setTimeout` 도 초당 1회로 깎여 2.5초 동안 3프레임밖에 못 합쳤다.
그래서 `composeFrame()` 을 따로 꺼냈다 — 영상 파일을 되열지 않고 **캔버스 픽셀로** 재려고.
(영상 디코딩도 같은 이유로 `loadedmetadata` 에서 타임아웃했다.)

## 판정

**`ready-for-review`** — 합성 로직과 녹화 왕복은 픽셀·바이트로 확인했다.
**진짜 카메라와 폰이 남았다.** 그 둘을 보기 전에는 `ready-to-share` 가 아니다.
