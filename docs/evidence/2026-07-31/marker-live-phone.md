`2026-07-30-marker-detect.md` 는 **합성 이미지**였다. 이 문서가 그것을 실기로 다시 잰 것이다.

## 무엇을 재려 했나

터틀봇3 **버거** 상판(138×178mm, 라이다 약 70mm 중앙)에 붙일 수 있는 마커로
몇 m 까지 잡히나. 실제로 붙일 수 있는 최대는 **앞뒤 35mm · 좌우 20mm** 다.


## 뒤집힌 것 셋

### 1. **24px 기준은 두 배 비관적이었다**

합성 이미지 실험이 "최소 16px(이상적) · 24px(흐림)" 을 냈다. 실기에서는
**12px 에서 87%** 가 나온다. D10 에서는 시뮬레이션이 Hamming 오류정정을 못 흉내내
**과대평가**했는데, 이번엔 반대로 **과소평가**했다. 방향이 어느 쪽이든
**합성 이미지로 임계를 정하지 않는다** 가 결론이다.

### 2. **AR.js 기본값이 폰에서 해상도를 두 번 깎고 있었다**

| | 기본 | 원인 |
|---|---|---|
| 카메라 요청 | 640×480 | `ArToolkitSource` 기본 |
| 검출 캔버스 | **320×240** | `ArToolkitProfile` 이 폰을 감지해 `phone-normal` 선택 |

둘 다 올린 결과 — **같은 35mm 마커가 58% → 100%** 가 됐다.
검출 캔버스만 320→640 으로 올린 판에서는 **인식률 58%→94%, fps 는 54→55 로 그대로**였다.
**대가 없는 개선이었고, 그것을 안 재봤으면 계속 절반 해상도로 돌았다.**

### 3. **기울기 걱정은 기우였다**

착수 전 판단은 "눕힌 마커를 서서 보면 34°, 유효 크기 56%로 깎인다" 였다.
실측 기울기는 **56~79°** 로 훨씬 비스듬한데 100% 가 나온다. 각도는 이 거리대에서
지배 변수가 아니었다.

## 확인하지 않은 범위

- **뒤집힘(pose ambiguity) 방어 코드는 만들지 않았다.** 회전 급변 최댓값이
  2~22° 로 30° 문턱을 한 번도 안 넘었다. **관찰되지 않은 문제를 먼저 막지 않는다.**
  다만 ±2.87m 로 크게 움직인 판 하나에서 39° 가 찍혔다 — 움직이면 나온다는 뜻이다.
- **20mm·25mm·45mm·55mm 는 재지 않았다.** 35mm 가 목표 거리를 넘겨서 더 내려갈 이유가 없었다.
- **각도 단독 효과를 분리하지 못했다.** 마커를 터틀봇 앞면에 세로로 붙인 채
  위에서 내려다보는 자세만 쟀다. 정면(기울기 20~30°) 판이 없다.
- **fps 13~14 의 원인을 못 좁혔다.** 검출 캔버스를 1280→960 으로 줄여도 그대로였다 —
  검출이 아니라 **카메라 영상 디코딩** 쪽으로 보이지만 확인 안 했다.
- **인쇄 배율을 자로 검산하지 않았다.** 화면의 `거리m` 이 줄자와 맞는지로 갈음했다.
- 폰 1대 · 조명 1종 · 실내 1곳. **다른 폰에서 재현하지 않았다.**

## 어떻게 쟀나 (재현 절차)

```bash
npm run dev -w @fr5/ar          # 포트 5173 고정
adb reverse tcp:5173 tcp:5173   # 폰이 localhost 로 인식 → HTTPS 없이 카메라가 열린다
```

폰에서 `http://localhost:5173/ar.html?bc=5&mm=35&src=1280&cv=960&sm=off&diag=1&log=1`

자리를 잡고 `⚙` → **[측정 30초]**. 그 30초가 한 판이고 `run` 번호가 로그에 박힌다.
원본은 `.diag/<날짜>.jsonl`(gitignore), 집계는 `python3 scripts/dev/report-diag.py --runs`.

**측정 규율** — 재는 동안 움직이지 않는다. `거리폭 ±0.3m` 를 넘으면 스크립트가 경고한다.
첫 판들이 ±1.8m 까지 흔들려서 "한 거리의 값" 이 아니었고, 그래서 [측정] 버튼을 만들었다.

## 판정

**버거 상판 35mm 마커는 쓸 수 있다** — `src=1280 · cv=960` 에서 1.8m 100%.
기본 설정(640×480 · 320×240)으로는 1m 안쪽 전용이라 못 쓴다.

**남은 값** — fps 13~14. 시각적으로 끊겨 보인다. 검출 해상도로는 못 푼다.
