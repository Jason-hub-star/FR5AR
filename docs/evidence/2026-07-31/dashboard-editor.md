## 고친 버그 넷 — 전부 **측정으로** 찾았다

### ① 끌면 카메라가 55m 밖으로 날아갔다

물체 좌표 계산은 **맞았다** (재현: 결과 3.18/5.59 · 기대 3.2/5.6).
콘솔로 카메라를 찍어 보니 `[55.29, 23.58, 41.85]` — OrbitControls 가 같은
`pointerdown` 으로 궤도를 시작했고, 화면 좌표가 캔버스 밖(`-341, 914`)이 됐다.

원인은 **끄는 시점**이었다. `stage.onTick(() => controls.enabled = !edit.isDragging())`
는 **다음 프레임**에 돈다. OrbitControls 가 먼저 등록돼 있어 이미 늦었다.

→ 리스너를 **캡처 단계**로 걸고, 물체를 집은 그 자리에서 `controls.enabled = false`
+ `stopPropagation()`. 측정: `카메라_안움직임: true`.

### ② 물건을 놓을 때마다 시점이 기본값으로 돌아갔다

`LayoutView` 의 `useEffect` 가 `[layout]` 에 걸려 있어, 커밋 → `layout` 새 객체 →
**무대를 통째로 다시 만듦** → 카메라 리셋. 편집 중에 이러면 못 쓴다.

→ 효과를 둘로 쪼갰다. **무대(카메라 포함)는 마운트에 한 번**, 내용물만 갈아끼운다.
시점 맞추기는 배치안 id 가 바뀐 첫 순간에만.

측정 — 카메라를 `[3, 14, 22]` 로 일부러 틀어 놓고 물건 하나를 옮긴 뒤:

| 항목 | 값 |
|---|---|
| 시점 유지 | **true** (`3,14,22` 그대로) |
| 무대 재생성 안 됨 | true |
| ch1 이동 | `1150, 3400` → `2000, 4600` (기대 1950 → 격자 100mm 스냅 2000) |
| 되돌리기 | (1) |

### ③ 링·좌표가 부모 좌표계와 섞여 있었다

호버·선택 링은 `scene` 에 직접 붙는데 물체의 **로컬** `position` 을 썼다.
지금은 방 그룹이 평행이동뿐이라 상수가 상쇄돼 맞아 보였다 — **회전·스케일이 하나만
끼면 조용히 틀린다.** `getWorldPosition` 과 `parent.worldToLocal` 로 명시했다.

### ④ 배치안을 갈면 아무것도 안 골라졌을 것이다

`pickRoot` 를 값으로 잡아두면 A↔B 전환 뒤 **죽은 그룹을 계속 겨눈다.**
함수로 받아 매번 현재 내용물을 묻는다.

## 폰

| 항목 | 값 |
|---|---|
| `touch-action` | `none` (안 끄면 페이지가 스크롤되며 `pointercancel` 로 끌기가 끊긴다) |
| 터치 끌기 | **된다** — hood1 `5600,7550` → `6100,8400` (100mm 격자) |
| 시점 유지 | true |
| 세로 스크롤 | 없음 |
| 픽셀비 | 좁은 화면 **1.5** (기본 2) — 흰색 모형이라 계단이 잘 안 보인다 |
| 회전 | **버튼**으로도 된다 (`90 → 180`). 폰에는 키보드가 없다 |

레이아웃은 `calc(100vh - 104px)` 매직넘버를 **없앴다**. 폰에서 머리글이 두 줄이 되는
순간 숫자줄이 화면 밖으로 밀렸다. 플렉스로 바꾸고 **`#root` 를 뚫었다** —
React 가 끼워 넣는 `#root` 에 높이를 안 주면 3D 칸이 0 이 되고, 절대배치한
힌트·패널이 머리글 위로 겹쳐 올라온다 (스크린샷으로 확인한 뒤 고쳤다).

## 아직 아닌 것

- **편집 결과가 저장되지 않는다.** React 상태에만 있다 — 새로고침하면 사라진다.
  슬롯형 config (`H` 단계) 에서 `Shared/data/config/` 로 내린다
- 배포는 **로컬 빌드 산출물 업로드**다. 모노레포 workspaces 는 하위 폴더에서
  `npm install` 이 안 풀린다 — Vercel 빌드로 옮기려면 루트 기준 설정이 따로 필요하다
- `dist` 7.2MB 중 6.6MB 가 **아직 안 쓰는** URDF·그리퍼 STL 이다
  (`publicDir` 이 `Shared/assets` 전부를 복사한다). L2 에서 팔을 세울 때 쓴다
