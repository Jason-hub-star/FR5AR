# ARCHITECTURE — 구조

분류: **SSOT**. 새 폴더를 만들거나 코드를 어디 둘지 모를 때 여기를 먼저 고친다.

## 전체 그림

```
[FR5 컨트롤러]  ──TCP :8080──  [브리지 서버 :5055]  ──REST/WebSocket──  [클라이언트]
   실물 로봇         공식 파이썬 SDK      FastAPI              ├─ 웹 조작 화면 (PC)
                                                              ├─ AR 화면 (폰)
                                                              └─ 유니티 펜던트 (기존)
```

**브리지 서버가 유일한 관문이다.** 클라이언트는 로봇과 직접 말하지 않는다.
이유 — 안전 상한을 한 곳에서 강제하고, 조종권 충돌을 한 곳에서 막기 위해서다.

## 폴더 구조

```
FR5Web/
├── CLAUDE.md · AGENTS.md          진입 문서
├── docs/                          SSOT (아래 참조)
├── server/                        브리지 서버 (Python)
│   ├── main.py                    FastAPI 앱 · 라우트
│   ├── robot.py                   Fairino SDK 감싸기 · 상태 폴링
│   ├── safety.py                  속도 상한 · 명령 검사
│   ├── owner.py                   조종권
│   └── kinematics.py              FK · 예상 경로 계산
├── web/                           브라우저 화면 (번들러 없이 시작)
│   ├── index.html                 조작 화면
│   ├── ar.html                    폰 AR 화면
│   ├── js/                        모듈
│   └── assets/FAIRINO_FR5/        URDF + STL 7개 (FR5UNITY에서 복사)
└── scripts/                       카테고리 폴더로만 둔다 (규약: scripts/README.md)
    ├── check/                     검증 게이트 — 실패 시 exit 1
    ├── dev/                       개발 중 실행
    └── assets/                    자산 복사·변환
```

**규칙** — 새 최상위 폴더를 만들기 전에 이 문단을 먼저 고친다.

## 각 층이 책임지는 것

| 층 | 하는 일 | 하지 않는 일 |
|---|---|---|
| 브리지 서버 | 로봇 연결, 상태 폴링·브로드캐스트, 안전 검사, 조종권, 지점 저장, 경로 계산 | 화면 렌더링 |
| 웹 조작 화면 | 3D 표시, 조작 UI, 지점 목록 | 안전 판단 (서버가 한다) |
| AR 화면 | 마커 정합, 실물 위 겹치기 | 로봇 명령 (1단계에서는 보기 전용) |
| 유니티 펜던트 | 기존 기능 유지 | — |

## 좌표계

| 곳 | 단위 | 축 |
|---|---|---|
| 로봇 · API 계약 | 도(°), 밀리미터(mm) | 로봇 베이스 기준 |
| URDF · 3D 내부 | 라디안, 미터 | Z-up |
| three.js 화면 | 라디안, 미터 | **Y-up** → `robot.rotation.x = -π/2` |
| AR 마커 | 미터 | 마커 원점 → 로봇 원점 변환은 설정값 |

**변환은 경계에서 한 번만.** 중간에서 또 바꾸면 원인을 못 찾는다.

## 상태 흐름

```
로봇 상태 폴링 (서버, 30Hz)
   → 안전 검사 통과분만
   → WebSocket 브로드캐스트 (전원)
   → 3D 관절 갱신 · AR 겹치기 갱신
```

명령은 반대 방향이되 **조종권을 가진 하나만** 통과한다. `stop`은 예외로 항상 통과한다.

## 아직 정하지 않은 것

- 기록 저장소 — 파일 / SQLite / Supabase 중 미정. 지난 프로젝트 Supabase 스키마 재사용 가능
- 바퀴로봇(ROS 2) 연계 지점 — 무대 확정 후
