# FEATURE-SPEC — 기능 명세

> PRD.md의 F1~F6를 ID·우선순위·의존으로 정밀화한다. 새 기능은 팀 회의에서 확정 후 등록한다.

## 우선순위

- **P0**: MVP 필수. 없으면 성공 판정 불가.
- **P1**: 정식화. V1 이후 보강.

## 기능

| ID | 기능 | 우선순위 | 의존 | 완료 판정 |
|---|---|---|---|---|
| F1 | 웹에서 로봇 조작 | P0 | — | 팀원이 자기 노트북 브라우저에서 관절을 움직인다 |
| F2 | 화면 속 쌍둥이 | P0 | F1 | 실물이 움직이면 브라우저 3D 로봇도 같이 움직인다 |
| F3 | 이동 지점 공유 | P0 | F1, F2 | A가 저장한 지점을 B가 불러 재생한다 |
| F4 | 폰으로 겹쳐 보기 | P0 | F2, F3 | 앱 설치 없이 QR로 열어 실물 위에 지점·경로가 보인다 |
| F5 | 조종권 | P0 | F1 | 지금 누가 조종 중인지 보이고 나머지는 관전한다 |
| F6 | 기록·되감기 | P1 | F1 | 명령·상태가 남고 나중에 되돌려 본다 |

## 의존 규칙

- F2는 F1의 상태 스트림에 의존한다.
- F3는 F1·F2에 의존한다.
- F4는 F2·F3에 의존한다.
- F5는 F1에 의존한다.
- F6은 F1에 의존한다.
