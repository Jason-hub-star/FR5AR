# scripts — 검증·빌드·자산 스크립트

규약과 기준값 위치는 `scripts/README.md` 에 있다. 여기서는 폴더만 안내한다.

## 폴더

| 경로 | 무엇 |
|---|---|
| `assets/` | 마커 시트/테스트 이미지 생성과 자산 동기화 |
| `build/` | `config.mjs` — `.env` 를 `Shared/data/config/*.json` 으로 굽는다 |
| `check/` | 검증·린트·문서 무게 체크 스크립트 |
| `dev/` | 개발 서버·배포 스크립트 |

읽을 것 — `scripts/README.md`
