# Vision — 비전 인식 · **미착수** (팀원 몫일 수 있다)

**비전은 로봇 명령을 만들지 않는다. 제안을 만든다.** 곧바로 명령이 되면 **하드 룰 3** 과
충돌한다. 죽으면 아무 일도 안 일어난다 (fail-closed). 폴더는 비어 있다 — 착수하면 여기에
구조를 적는다.

## 이미 정해진 것 — 다시 논의하지 마라

1. **`/proposal` 은 로봇을 안 움직인다.** 실행은 `approve`, 승인분은 `moveJ`·`gripper` 로
   **번역**돼 같은 게이트를 다시 탄다 — 비전 전용 실행 경로는 없다
2. **`auto` 통과는 닫혀 있다.** 전부 `needsHumanConfirm`
3. **마지막 구간은 아무것도 안 보인다.** 컬러가 손끝 아래 36mm 에서 먼저, 깊이가 2mm 에서
   끊긴다(D69) → 앵커로 봉인. **closed-loop 도 "파지 순간 RGB 만" 도 기각됐다**
4. **관문이 어느 기계에서 도는지는 미정**(D61). 계약은 주소만 약속하니 지금도 짤 수 있다
