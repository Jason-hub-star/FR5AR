# /카메라 — 폰을 카메라로 붙인다

`/우분투` 의 카메라판이다. 세션마다 **"붙었나 → 서버 켜졌나 → 값 잠겼나 → 검출되나"** 를
처음부터 다시 밟게 되는데, 그 넷을 대신 돌리고 **판정만 보고**한다.

앱은 IP Webcam(`com.pas.webcam`) · 포트 8080 · 영상은 `\<주소\>/video` (MJPEG).
근거와 실측은 `docs/evidence/2026-08-04/global-cam-phone.md` · **D64**.

## 순서 (막히면 그 단계에서 멈추고 보고한다)

### 1. 어디로 붙나 — 유선이 먼저다

```bash
adb devices -l
adb forward tcp:8080 tcp:8080        # 케이블을 다시 꽂으면 사라진다. 매번 건다
```

기기가 보이면 `HOST=localhost:8080`. 안 보이면 무선으로 간다 —

```bash
adb shell ip -4 addr show wlan0 | grep inet     # 폰이 와이파이에 붙어 있을 때
```

폰이 셀룰러만 잡고 있으면 `192.0.0.4` 같은 통신사 주소가 나온다. **그건 못 닿는다.**
`adb shell svc wifi enable` 로 켜고 다시 본다. 케이블이 아예 없으면 폰 IP 를 사람에게 묻는다.

**유선을 기본으로 권한다** — 충전이 같이 되고(발열이 붙으면 폰이 스스로 화질·프레임을 깎는다),
캠퍼스 망 정책과 무관하고, `localhost` 는 보안 출처라 https 배포본에서도 안 막힌다.
무선(`192.168.x.x`)은 겹쳐 보기를 **로컬 dev(http)** 로 열어야 한다.

### 2. 서버가 켜져 있나

```bash
curl -s -m 3 -o /dev/null -w '%{http_code}\n' http://$HOST/status.json
```

`000` 이면 앱이 꺼졌거나 서버를 안 켠 것이다. 앱만 띄우고 **"서버 시작" 은 사람이 누른다** —

```bash
adb shell monkey -p com.pas.webcam -c android.intent.category.LAUNCHER 1
```

폰 UI 를 자동으로 눌러 넘기려 하지 않는다. 홈으로 튀어 남의 폰을 더듬게 된다.

### 3. 값을 잠근다

```bash
bash scripts/map/cam-lock.sh --host $HOST
```

해상도(2560×1440)·JPEG 화질·화이트밸런스·줌·초점을 넣고 **되읽어 확인**한다.
`바꾼다 …` 줄이 뜨면 **앱이 재시작해 설정이 조용히 풀렸던 것**이다 — 그 사실을 보고한다.

⚠ **초점은 `focus_distance` 로 잠그지 않는다** (D64). 이 폰에서 그 값은 되읽어도 참이
아니다 — 요청값이 그대로 돌아오는데 렌즈는 거기 없다. `auto` + `/focus` 1회로 맞추고
**선명도 수렴**으로 판정한다. 스크립트가 그렇게 한다.

### 4. 실제로 검출되나 — 여기까지 해야 "붙었다"

인쇄물(ChArUco 또는 태그)을 카메라에 보이게 두고 프레임을 받아 검출한다.
보드 제원은 `Shared/assets/tag/tags.json` 이 정본이다 (숫자를 다시 적지 않는다).

```
cv2.VideoCapture(f'http://{HOST}/video') → CharucoDetector(...).detectBoard(gray)
```

**판정** — ChArUco 코너 20개 이상이면 촬영을 시작해도 된다. 태그는 `aim.py` 가
px/칸 5.0 을 안전선으로 본다.

## 안 잡힐 때 — 원인을 셋으로 가른다

**순서를 지킨다.** 오늘(2026-08-04) 크기·높이·인쇄물을 먼저 의심하다 하루를 썼는데
범인은 초점이었다.

| 먼저 볼 것 | 재는 법 | 그 값이면 |
|---|---|---|
| **① 초점** | 보드 영역 라플라시안 분산 | 수백 이하면 초점이다. `/focus` 를 다시 걸고 수렴을 본다 |
| **② 크기** | 마커 한 변 픽셀 | **32~40px 아래면 해독이 안 된다.** 확대해도 안 살아난다 — 해상도를 올리거나 가까이 간다 |
| **③ 대비** | 밝기 2%·98% 백분위 차 | 130 아래면 조명·용지 반사다 (`AR-MARKER.md` 실측) |

①이 아닌 것을 확인하기 전에 ②③으로 넘어가지 않는다. 셋 다 아니면 **보드가 시야 밖**이다 —
프레임을 저장해 눈으로 본다. 검출 0 의 절반은 "볼 게 없었다" 였다.

## 보고 형식

- 붙은 경로(유선/무선) · 해상도 · fps
- 잠금 결과 — **바뀐 값이 있었으면 그것부터.** 풀려 있었다는 사실이 다음 판을 지킨다
- 검출 결과 — 코너/마커 개수와 픽셀 크기
- 안 되면 위 표의 **어느 단계에서 갈렸는지**
