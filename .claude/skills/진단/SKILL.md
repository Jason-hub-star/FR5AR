# /진단 — 근본 원인까지

증상만 고치지 않는다. **원인을 찾아 한 곳에서 고친다.**

## 증상별 런북 (실제로 겪은 것들)

### 3D 로봇이 안 뜬다 / 화면이 통째로 빈다
1. 브라우저 콘솔이 아니라 **네트워크 요청**을 먼저 본다. 모듈 로드 실패는 에러 메시지가 안 나온다.
2. `three.core.js` 404 — three.js r185부터 빌드가 `three.module.js` + `three.core.js` 두 파일이다.
   CDN에서 module만 받으면 화면이 통째로 죽는다.
3. `urdf-loader`가 `ColladaLoader`를 정적 import 한다. Collada 의존 사슬
   (`TGALoader` · `ColladaParser` · `ColladaComposer`)까지 있어야 뜬다. 우리 메시는 전부 STL이라
   번들러를 쓰면 자동 해결된다.

### 3D는 뜨는데 메시가 없다 / 삼각형이 0개다
`load` 콜백 시점에는 **STL이 아직 안 붙었다.** 비동기다.
삼각형 수를 세거나 바운딩 박스를 잡는 코드를 콜백 안에 두면 틀린 값을 얻는다.

### 폰에서 카메라가 안 열린다
`http://192.168.x.x` 로는 **절대 안 된다.** 브라우저가 안전한 연결이 아니면
`navigator.mediaDevices` 자체를 주지 않는다. 코드 문제가 아니다.
→ mkcert 또는 터널로 HTTPS를 먼저 세운다.

### 로봇이 엉뚱한 자세로 간다
단위와 좌표계를 의심한다.
- API 계약 바깥면은 **도(°)·밀리미터(mm)**, URDF·3D 내부는 **라디안·미터**
- URDF는 **Z-up**, three.js는 **Y-up** (`robot.rotation.x = -PI/2`)
- 변환이 두 곳에서 일어나고 있는지 grep 한다. 한 곳에만 있어야 한다.

### 겹쳐진 로봇이 떨린다
마커 검출이 프레임마다 튄다. 최근 몇 프레임 평균을 쓰고, 마커를 놓쳐도 마지막 위치를 유지한다.

### SDK 설치가 안 된다
`pip install fairino` 는 **실패한다. PyPI에 없다.**
컴파일된 확장 모듈이라 파이썬 버전·OS별 바이너리를 골라야 한다
(`cpython-310/311/312`, win/linux 별도).

### SDK에서 필드를 못 찾는다
**중국어 주석이다.** 영어 관용어로 찾으면 놓친다.
`drift`가 아니라 `cmdPointError`, 비상정지는 `EmergencyStop`(`急停标志`)이다.
→ 이름으로 찾지 말고 **필드 목록을 통째로 뽑아 훑는다.** `AGENTS.md` §"없다"고 말하기 전에

### 게이트가 실패한다
```bash
bash scripts/check/harness.sh   # 커맨드·스킬·훅 개수
bash scripts/check/docs.sh      # 필수 문서·INDEX 등재·깨진 링크·Unity 배너
bash scripts/check/assets.sh    # URDF·메시·삼각형 수
```
기준값을 바꿨으면 `scripts/README.md`의 표에서 해당 상수도 고쳤는지 본다.
안 고치면 **게이트가 거짓으로 실패**한다.

## 이 런북은 자란다

위 목록은 **실제로 겪은 것만** 적혀 있다. 추측한 함정은 넣지 않는다.

**새 함정을 만나면 이 문서에 한 항목을 추가한다.** 형식은 위와 같다 —
증상 한 줄 → 원인 → 확인 방법. 세 줄을 넘기지 않는다.

이미 겪은 것의 상세는 `docs/evidence/`에 날짜별로 있다. 이 런북은 **색인**이고,
근거는 evidence다. 여기에 긴 설명을 쓰지 않는다.
