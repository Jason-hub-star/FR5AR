# /마감 — 닫는다

## 절차 (순서 고정)

### 1. 게이트
```bash
bash scripts/check/all.sh
```
**실패하면 마감하지 않는다.** 고치거나, 못 고치면 GAP-MATRIX에 OPEN으로 남기고 이유를 적는다.

### 2. 증거 확인
이번 세션에 3D·AR·서버 동작을 바꿨는가?
- 바꿨는데 **실렌더·실요청으로 확인 안 했다면 완료가 아니다.** 확인하거나 미완으로 남긴다.
- 확인했으면 `docs/evidence/YYYY-MM-DD/<주제>.md` 로 남긴다 (**날짜가 폴더**) — 무엇을 어떻게 확인했고,
  **확인하지 않은 범위**까지 적는다.

### 3. 얇은 문서 갱신 (얇게)
- `docs/status/PROJECT-STATUS.md` — 완료·다음 걸음·블로커만. 상세는 evidence로 보낸다.
- `docs/status/GAP-MATRIX.md` — 닫힌 것 CLOSED, 새로 발견한 것 OPEN 추가
- 결정을 했으면 `docs/status/DECISION-LOG.md` — 결정·이유·기각한 대안

### 4. 개수·기준값 점검
스킬·커맨드·문서·자산을 늘리거나 줄였으면 **해당 상수도 고쳤는지** 확인한다.
`scripts/README.md`의 기준값 표를 본다. 안 고치면 다음 세션에 게이트가 거짓 실패한다.

### 5. 완료 판정 (release verdict)
*(흡수: `/마감`)*

셋 중 하나로 정한다. **증거가 없으면 자동으로 `not-ready`다.**

| 판정 | 뜻 |
|---|---|
| `not-ready` | 검증 안 됨 또는 게이트 레드. 완료로 적지 않는다 |
| `ready-for-review` | 검증했으나 남은 리스크가 있다 |
| `ready-to-share` | 검증 끝, 팀에 보여도 된다 |

함께 적을 것 — **실제로 실행한** 검증 명령(적기만 한 것 금지) · 바뀐 문서와 이유 ·
**아직 확인 못 한 가정** · 남은 리스크.

### 6. 핸드오프 캡슐
*(흡수: `session-handoff`)*

다음 세션이 **바로 이어받을 수 있게** 넷을 적는다.

1. **시작 지점** — 다음에 열 문서 또는 파일 경로. **실제 존재하는 경로여야 한다.**
2. **먼저 읽을 것 1~3개** — 그 이상 적지 않는다
3. **막힌 것과 미결 결정** — 왜 막혔는지까지
4. **다시 시작할 때 돌릴 첫 명령** — 보통 `bash scripts/check/all.sh`

기록 위치는 `docs/status/PROJECT-STATUS.md`. 막혀서 중단하는 경우에도 **안전한 다음 행동**을 남긴다.

### 7. 커밋 — **마감이 커밋까지 한다** (2026-08-05 변경)

승인을 따로 묻지 않는다. **게이트가 green 이고 5번 판정이 `not-ready` 가 아니면 커밋한다.**
마감했는데 안 커밋된 상태가 남으면 다음 세션이 남의 작업과 섞인 트리를 받는다.

- **커밋 전에 `git status --short` 를 보고 범위를 보고한다.** 이번 세션이 안 건드린 파일이
  섞여 있으면 **개수와 폴더를 말한 뒤** 커밋한다 — 숨기지 않는다
- **메시지는 한국어**로, 최근 커밋의 문체(`fix: 잠갔다고 믿은 초점이 거짓이었다 (D64)`)를 따른다.
  D번호가 있으면 넣는다
- **푸시는 안 한다.** 커밋은 되돌릴 수 있고 푸시는 밖으로 나간다 — 푸시는 따로 명령받는다
- 기본 브랜치(`main`) 위면 **브랜치를 먼저 딴다**
- 아직 `git` 저장소가 아니면 그 사실을 알린다

**커밋하지 않는 경우** — 게이트 레드 · 판정 `not-ready` · 사용자가 이번엔 하지 말라고 한 때.

## 하지 말 것

- 게이트 레드 상태로 마감
- 검증 안 한 것을 완료로 적기
- PROJECT-STATUS를 길게 쓰기 (상세는 evidence)
- **커밋했다고 푸시까지 하기**

## 상태판은 얇게 유지한다

`/마감` 이 흡수한 것 — 얇은 상태판 규칙(`references/얇은-상태판.md`) · 핸드오프 캡슐 ·
완료 선언 전 근거 확인. **문서를 붙이기 전에 먼저 중복·오래된 상태·폐기된 실험을 정리한다.**

문서가 무거워졌는지는 `bash scripts/check/docs-weight.sh --weekend` 가 판정한다 —
이관 후보를 보고하고, **옮기는 것은 이 명령에서 사람이 확인하고 한다** (D18).
