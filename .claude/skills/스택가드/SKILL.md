# /스택가드 — 박기 전에 등재

코드에 **하드코딩되는 순간 드리프트가 시작된다.** 박기 전에 문서에 올린다.

## 대상 (하나라도 해당하면 이 스킬을 부른다)

- 라이브러리 버전 (`three@0.185.1` 같은 것)
- SDK 필드명 (`cmdPointError` · `mc_queue_len` 같은 것)
- API 엔드포인트·WebSocket 메시지 이름
- 포트 번호·IP
- 삼각형 수·용량 같은 기준값
- 외부 URL

## 절차

1. **`docs/ref/STACK.md`에 있는지 확인한다.** 없으면 추가한다 — 값 + **출처** + 확인 날짜.
2. SDK 필드라면 **원문 주석을 함께 적는다.** 중국어라도 그대로.
   번역만 적으면 다음 사람이 원본에서 못 찾는다.
3. 기준값이라면 `scripts/README.md`의 **기준값 표**에도 올린다.
   어느 스크립트의 어느 상수인지, 언제 바꿔야 하는지.
4. API 계약이라면 `docs/ref/API-CONTRACT.md`를 고친다. **여기가 SSOT다.**

## FAIRINO SDK 필드를 다룰 때 (특히 위험)

- **이름을 추측하지 마라.** 중국어 주석 기반이라 영어 관용어가 안 통한다.
  `drift`가 아니라 `cmdPointError`, 비상정지는 `EmergencyStop`(`急停标志`)이다.
- 필드 목록을 **통째로 뽑아 훑는다.** 근거: `docs/evidence/2026-07-30/sdk-state-fields.md`
- **개수를 적을 때 세는 단위를 밝힌다.** 구조체 필드 150개와 추출 건수 292개는 둘 다 맞다.

## 문서 등재만으로는 부족하다 — 런타임으로 확인한다
*(흡수: `api-contract-guard`)*

문서에 적는 것은 절반이다. **실제로 그 값이 맞는지 확인한 뒤** 적는다.

| 확인 대상 | 확인 방법 |
|---|---|
| SDK 필드명 | 원본 파일에서 구조체 정의를 직접 읽는다. 목록을 통째로 뽑아 훑는다 |
| API 응답 필드 | **실제 응답을 받아 본다.** 문서만 보고 적지 않는다 |
| 스키마 · 컬럼명 | 스키마 파일 또는 마이그레이션을 본다 |
| 라이브러리 버전 | 레지스트리(npm·PyPI)를 조회한다 |
| 엔드포인트 | 실제로 호출해 상태 코드를 본다 |

확인 못 했으면 **"미확인"이라고 적는다.** 확인된 것과 섞지 않는다.

## 상수는 한 곳에 모은다

같은 값이 두 곳에 있으면 그 자체가 드리프트다.
- 서버 — `server/` 안의 설정 모듈 한 곳
- 웹 — JS 모듈 한 곳
- 게이트 기준값 — 스크립트 상단 상수 (`scripts/README.md` 표에 등재)

버전에 의존하는 분기를 넣을 때는 **왜 그 버전인지 주석으로 남긴다.**
이유 없는 버전 분기는 다음 사람이 지우지 못한다.

## 검증

bash scripts/check/docs.sh    # FR5UNITY 경로를 인용하며 유니티임을 안 밝힌 문서를 잡는다
