# /검진 — 문서 뼈대 린트

게이트는 O/X만 준다. 이 스킬은 **무엇부터 고칠지**를 정한다.

## 실행

```bash
bash scripts/check/docs.sh
```

검사 항목 넷 — 필수 SSOT 존재 / INDEX 등재 / Unity 배너 / 깨진 상대링크.

## 결과 해석 (고칠 순서)

### 1순위 — 필수 문서 없음
SSOT가 빠진 것이다. 다른 모든 것보다 먼저 만든다. `REQUIRED` 배열이 목록이다.

### 2순위 — INDEX 미등재
문서는 있는데 지도에 없다 = **아무도 못 찾는다.** `docs/INDEX.md` 표에 한 줄 추가하고
`## 자가검증`의 개수도 같이 올린다.

### 3순위 — Unity 배너 누락
`docs/ref/unity/` 안의 문서에 출처 배너가 없다.
**Unity 기준 내용을 웹 기준으로 오인하면 좌표계가 어긋난다.** 배너 문구는 `docs/INDEX.md`에 있다.

### 4순위 — 깨진 링크
문서를 옮기거나 이름을 바꾼 흔적이다. 링크를 고치거나 대상을 복구한다.

## 추가로 볼 것 (게이트가 안 잡는 것)

- **오래된 기록** — "미착수"라고 적힌 것이 이미 끝났는지. 실제로 겪은 사고다
  (자산 복사가 끝났는데 `PROJECT-STATUS`는 "복사 안 됨"이었다).
- **개수 불일치** — INDEX의 `자가검증` 개수와 실제 행 수:
  ```bash
  grep -cE '^\| `' docs/INDEX.md
  ```
- **evidence에 한계가 적혀 있나** — 확인한 범위만 있고 **확인 안 한 범위**가 없으면 위험한 문서다.

## 하지 말 것

- 게이트만 통과시키고 내용은 안 보기
- 고아 문서를 INDEX에 올리기만 하고 역할 설명을 비워두기
